# 👋 Hello Android - Greetings App



Dies ist mein erstes Jetpack Compose Projekt im Rahmen des Android-Kurses:  

👉 [Android Basics with Compose – Unit 1, Pathway 2](https://developer.android.com/courses/pathways/android-basics-compose-unit-1-pathway-2)



---



## 🎯 Ziel des Projekts



Das Ziel der App ist es, eine einfache Begrüßungsnachricht auf dem Bildschirm anzuzeigen. Dabei werden grundlegende Jetpack Compose Konzepte wie:

- `@Composable` Funktionen

- `setContent` zum Definieren des UI

- Layout-Elemente wie `Text`, `Column` und `Surface`

- Themes und Modifier



verwendet.



---



## 🛠️ Features



- Anzeige eines Grußtexts

- Nutzung von `MaterialTheme`

- Einfache UI-Struktur

- Saubere Trennung von UI-Komponenten
